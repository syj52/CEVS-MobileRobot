# AGV二位导航地图一键生成说明 (`generate_map.py`)

## 简介
目前所有的地图提取、空间变换解析和图像光栅化绘图，都被合并成了单一的终端指令集 `generate_map.py`。该脚本直接读取包含了三维实体位移参数的二进制 `.glb` 文件进行判定，不再需要经过 `trimesh` 库中间转存 `PLY`。

## 基本使用方法

打开终端，进入到此目录执行：
```bash
python3 generate_map.py --glb corridor_point.glb --zmin 0.1 --zmax 0.6
```

## 可调整的核心参数说明

| 参数名称 | 默认值 | 作用和意义 |
|---------|-------|-----------|
| `--glb` | `corridor_point.glb` | 数字孪生系统中，你导出并替换在这个文件夹下的 3D 地图原数据。 |
| `--zmin` | `0.0` | **截平面厚度的最低界限（米）**。在前端的数字孪生系统中通过「高度-厚度/2」推算获得。数值越低，切入地面越多。 |
| `--zmax` | `1.0` | **截平面厚度的最高界限（米）**。超过该高度的屋顶天花板点云会被忽略。只提取在 `zmin` 和 `zmax` 范围内的点生成墙体。 |
| `--resolution` | `0.05` | 地图精度（像素分辨率）。0.05 代表图上每一格（1个像素）等于现实中 5 厘米。 |
| `--margin` | `10` | 地图周边的留白边界格子数量。增加留白以确保 AGV 不会走入地图的边界触发越界报错。 |
| `--robot-radius` | `0.0` | **AGV机身防撞膨胀半径（米）**。如果你发现 AGV 在贴墙走时容易剐蹭，可以把这个值调为（比如） `0.2` 或 `0.3`。脚本会自动基于这半径做腐蚀膨胀运算生成安全的肥厚安全黑边。 |
| `--out-dir` | `.` | 生成的 PGM / YAML 地图结果和 PNG 预览图的输出位置，默认为当前文件夹。由于最终网页界面在同文件夹读取，请不要改变这个设定。 |
